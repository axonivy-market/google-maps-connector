# Google Maps Connector
Mit der [Google Maps
API](https://developers.google.com/maps/documentation/javascript/overview) von
Axon Ivy können Sie Karten mit Ihren eigenen Inhalten anpassen, um sie auf
Webseiten und Mobilgeräten anzuzeigen.

Der Konnektor:

- bietet vier grundlegende Kartentypen (Straßenkarte, Satellitenkarte,
  Hybridkarte und Geländekarte), die Sie mithilfe von Ebenen und Stilen,
  Steuerelementen und Ereignissen sowie verschiedenen Diensten und Bibliotheken
  anpassen können.
- Bietet Zugriff auf die Kern-API der Google Maps Platform.

## Einrichtung

1. Erstellen Sie einen neuen [Google
   API-Schlüssel](https://developers.google.com/maps/documentation/javascript/get-api-key#creating-api-keys).
2. Kopieren Sie den API-Schlüssel in Ihre Datei „ `variables.yaml“`.

```
Variables:

  google.map.api.key: 'your api key'
```
